# 风电预测论文投稿约束清单

> 来源：基于 EPSR-D-26-06657《Time-Series Wind Power Forecasting Framework for Extreme Weather via Physics-Guided Priors and Dynamic Multi-Graph Fusion》对 5 位审稿人（R1/R2/R3/R5/R7）意见回复的经验提炼。
> 用途：作为 PR-Warn++（目标 IEEE TSTE）及其后续论文的实验设计、写作与投稿前自检规范。
> 每条约束标注其来源审稿问题（如 R1.1 = Reviewer 1 Comment 1）；标注「用户指定」的为用户明确要求。
> 版本：v1.0 · 2026-10-10

---

## 0. 元约束（用户指定，优先级最高）

| ID | 约束 | 说明 |
|---|---|---|
| C0-1 | **实验数据集 ≥ 3 个** | 至少 3 个不同风场/配置的数据集；其中必须含跨数据集可复现性验证（如 within-farm retraining，同一时序切分、输入契约、调参预算、多 seed 协议），不能只有单风场结果 |
| C0-2 | **多 seed 实验 ≥ 10 次** | 可训练模型的随机种子数至少 10 个（多 seed ≥ 10），报告 mean ± SD；少于 10 个种子不足以支撑核心创新点的统计结论（来源：R1.3 中 3 种子标准差吞没差异的教训） |

## 1. 定位与证据一致性

| ID | 约束 | 来源 |
|---|---|---|
| C1-1 | 标题/引言/摘要主打的概念（如"极端天气""鲁棒性"）必须有**独立的实验证据**支撑；禁止用全量测试集平均代替事件级/条件级证据 | R1.1, R2.2, R7.1 |
| C1-2 | 特殊条件（极端天气等）必须有**可执行的操作化定义**：训练集拟合阈值并冻结（给出具体阈值数值与分位数），阈值选择不得使用验证/测试观测 | R1.1, R3.18, R5.1 |
| C1-3 | 事件级结果单独成表，与全量结果分离报告；公开事件/样本计数（如 207/23/92 个链接窗口），子集样本过少时如实说明 | R1.1, R2.2, R5.1 |
| C1-4 | 事件标签窗口按完整预测视野归属切分，不得跨冻结切分边界 | R3.19, R5.2 |

## 2. 核心创新点证据链

| ID | 约束 | 来源 |
|---|---|---|
| C2-1 | 每个核心卖点必须有**独立证据链**（matched controls + 干预实验），禁止用单一混合因素对比（如"E4 vs E6"同时改多个因素）证明创新 | R1.3, R2.1 |
| C2-2 | 关键对比必须报告：配对差异（paired difference）、95% CI、效应量（effect size）、p 值；多重比较用 Holm 校正 | R1.3 |
| C2-3 | 分离"幅度"与"独立性"：主贡献与补充贡献分别表述，不混为一谈 | R2.1, R3.9 |
| C2-4 | 机制解释只写到证据支持的程度：门控权重是预测混合系数，不得声称因果/尾流物理；混淆因素（限电、共享控制、缺失气象因素）需用代理分层分析 | R2.7, R7.3 |
| C2-5 | 结果族分离标注（如 submitted protocol vs revision protocol），不同协议的结果不混用、不跨比 | R2.5 |
| C2-6 | 干预对照应含：frozen（冻结为验证集均值）、uniform、shuffled、parameter-matched 非门控等 | R1.3, R2.1, R2.7 |

## 3. 实验完备性

| ID | 约束 | 来源 |
|---|---|---|
| C3-1 | 数据集 ≥ 3 个，含独立风场 within-farm retraining 验证（同协议） | R2.3 + 用户指定 |
| C3-2 | 多 seed ≥ 10 次，报告 mean ± SD | 用户指定 |
| C3-3 | 必须提供概率/不确定性输出（校准区间或场景）；校准与测试时间分离，事件类型行不得做事件级重校准 | R2.9 |
| C3-4 | 鲁棒性扰动按**训练统计量缩放**（如 0.10–1.00 × 训练 SD），缺失测试覆盖：随机点/时间块/特征级/关键气象通道；派生量（密度、等效风速）重算而非独立扰动；报告**绝对退化**（相对各模型干净参考）而非百分比 | R2.6 |
| C3-5 | 基线公平性：统一输入契约、预处理、掩码、原始单位、调参预算、选择规则；超参与 checkpoint 只在验证集选择，绝不触碰测试集 | R2.5 |
| C3-6 | 计算成本：Big-O 复杂度（稀疏/稠密实现分开给出）+ 统一硬件实测（参数量/FLOPs/时延/吞吐/训练时间/峰值内存，注明 warm-up 与计时协议） | R1.4, R2.4, R3.26 |
| C3-7 | 参数敏感性：one-factor-at-a-time，只在验证集评估，报告各参数最大退化与是否处于搜索边界 | R3.20 |
| C3-8 | 数据可复现：给出数据集 DOI/文件名/file ID/MD5；区分"发布数据自带字段"与"作者处理"；时间对齐只在训练集拟合 | R1.1, R7.2 |

## 4. 统计与指标口径

|---|---|---|

## 5. 方法与写作透明性

| ID | 约束 | 来源 |
|---|---|---|
| C5-1 | 贡献分层声明：主贡献 / 补充贡献 / 评估系统；引用既有公式（如 IEC 61400-12-1 密度归一化、Buck 1981）时不得 claim 独立创新 | R1.2, R3.9, R3.10 |
| C5-2 | 公式三级分类标注：既有操作（带引用）/ 研究特有算子（显式写出）/ 系统级构造（集成创新） | R3.10 |
| C5-3 | 每式/每组公式后加直觉解释：变量含义、做了什么变换、结果在预测管线中的作用 | R3.11 |
| C5-4 | 参数-系统含义表（类别、模型角色、风场/物理含义、单位、数值、选择来源）+ 参数来源五分类（task-definition / data-fitted / geometry-derived / validation-selected / budget-fixed） | R3.14, R3.19, R5.2 |
| C5-5 | 与最相近 SOTA 方法（如 physics-constrained Transformer、AGCRN、Graph WaveNet、MTGNN）的四维对比表：指导如何进入预测目标 / 空间表示 / 时序骨干 / 可 claim 的差异化范围 | R3.15, R3.16 |
| C5-6 | 文献综述先声明覆盖主题与选择逻辑；评述各方法族的强弱与对结论有效性的影响 | R3.7, R3.8 |
| C5-7 | research gaps 独立成节（证据驱动），problem formulation 紧随其后；结构为"文献综合 → 缺口 → 问题表述 → 方法" | R3.12, R3.13 |
| C5-8 | 图：矢量导出、按实际栏宽检查字号、图注说明聚合范围与参数物理含义；示意图明确标注非数据结果 | R3.21, R3.23, R5.5, R7.4 |
| C5-9 | 提供流程图 + 编号分步程序（含关键参数），端到端可追踪 | R3.24 |
| C5-10 | 研究问题用五条可检验标准论证：决策相关可测输出 / 未解决的方法空白 / 明确边界 / 可证伪 / 可复现 | R3.3 |

## 使用方式

1. **实验设计阶段**：按第 0–3 章逐条确认（数据集数量、seed 数、事件定义、对照实验、鲁棒性协议），缺项即为设计缺口。
2. **写作阶段**：按第 5–6 章自检（贡献声明、公式标注、参数表、图表、摘要结论结构）。
3. **投稿前**：C6-8 交叉引用审计、C6-9 全文校对、C1-4 切分边界复查、C4-4 指标可重算归档。
4. **返修阶段**：审稿意见逐条映射到本清单对应约束，缺证据的约束即为必补项。
