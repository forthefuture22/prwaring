③ 标准做法要点
1. 四类对照成套出现：uniform（均匀权重）/ frozen（固定为验证集均值静态权重）/ shuffled（固定种子打乱 batch 对应）/ parameter-matched（参数量相同但无学习式门控）（Wiegreffe & Pinter 2019）。
2. uniform 是零假设基线：4 图等权混合（1/K），检验非均匀加权是否必要。
3. frozen 是「静态 vs 动态」关键对照：常数权重向量=验证集上对 learned gate 输出求平均；与 learned 之差即动态输入相关门控的净贡献。
4. shuffled 检验「输入→权重」映射是否被因果使用：保持边缘分布、仅打破样本对应；若性能几乎不变则该映射未被因果利用（Jain & Wallace 2019；Michel 2019）。
5. parameter-matched 排除参数容量混淆：保留 gate MLP 参数量但输出固定分布并阻断梯度（Wiegreffe & Pinter 2019；Michel 2019）。
6. 分两类执行：uniform/parameter_matched 可从头训练（进矩阵）；frozen_mean/shuffled 是已训练 checkpoint 上的后验推理干预（独立 CLI，只读验证集）。
7. 附带门控权重统计量：各图权重均值/标准差/跨样本方差（backbone.py:244 已输出 graph_weights）。
8. 结论措辞有界：只声称「动态门控相对对照的改善」，不声称 gate 编码尾流/因果物理（C2-4）。

③ 标准做法要点
3-1 配对效应量（Cohen's d 配对版）：差值 d_i = a_i − b_i；均值差 M_d；差值 SD：SD_d = sqrt(Σ(d_i−M_d)²/(n−1))（ddof=1）；d_z = M_d / SD_d（无量纲，与 DM 同一差值序列配套）；小样本校正 Hedges' g = J·d_z，J = 1 − 3/(4(n−1) − 1)；判读沿用 0.2/0.5/0.8。
3-2 Holm step-down：① p 升序 p_(1)≤…≤p_(k)；② 从 i=1 起 p_(i) < α/(k−i+1)；③ 到第一个不满足的 i* 停，之前全拒绝；④ 调整后 p：p̃_(i)=max_{j≤i}(k−j+1)·p_(j)，截断 ≤1。
3-3 接入关系：diebold_mariano 不动签名；CI 复用 event_bootstrap_ci（事件簇）或 M_d±z·SE（newey_west_variance）；k=同一张表内要比较的基线/变体个数，报告显式写 k 与 α。

③ 标准做法要点
1. Transformer 基线：encoder-only（Vaswani 2017 编码器部分），[B·N, L, d_model] + 位置编码 + N 层 TransformerEncoderLayer，取最后时间步接线性头。
2. PatchTST：patching（patch_len/stride）+ channel-independence（与现有 _encode 的 reshape(batch*nodes, history, width) 一致）+ flatten 后线性预测头（Nie 2023）。
3. iTransformer：inverted embedding（每 variate 的 [L] 序列→d_model token）+ 注意力跨 variate + FFN 逐 token + 每 variate 线性输出（Liu 2024）。
4. 公平契约（C3-5）：同 deterministic_train.h5 残差（target_mode: physics_residual）、同 mask/delta_t 输入、同 masked_huber_loss、同调参预算（搜索空间/GPU 小时上限）、验证集选超参。
5. XGBoost：独立训练路径，逐节点逐 horizon；作为「经典 ML 上界」对照（Chen & Guestrin 2016）。
