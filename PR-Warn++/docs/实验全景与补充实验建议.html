§8 盘点结论
1. 整体覆盖度：28 项实验已搭起卖点证据骨架，主流指标均已实现接线；但对照顶刊常规 10 类实验，无一类达到「完整分解/对比」标准——6 类部分覆盖、4 类未设计，最高风险空白仍是事件级证据链（extreme_rmse/mae/picp 声明却零实现）。
2. 领域常规中最该补的 3 类：① #4 异常/极端事件检测的条件技能表（标题主打「extreme weather」的唯一独立证据来源，全量平均会被事件内外误差稀释，投稿被批概率最高，缺口 2 已覆盖务必落地）；② #2 跨季节/风况/场址分段评估（单数据集+单时序 split 无法支撑「空间图/物理先验可迁移」claim，缺口 1 已覆盖）；③ #1 逐 horizon 点/概率误差曲线（区间已逐步、点与 CRPS 跨步聚合，补这一步成本极低）。
3. 方法专属最该补的 3 个：S2 共形条件覆盖审计（回应 marginal≠conditional 头号质疑 + 顺手落地 rolling_picp）；S1 门控权重工况分布诊断（零新模型、只读已落盘 graph_weights，与缺口 3 形成「有用+合理」双证据）；S3 物理中心误差传播分解（把弱物理先验从结构性卖点落成可归因证据）。
